TileKeeper Technical Architecture

Local-first Expo React Native app with optional serverless cloud services

Decision

Expo React Native + TypeScript with a custom deterministic layout engine. Unity/Godot rejected as too heavy for a local-first inventory planner.

Cloud posture

No mandatory backend. Serverless catalog, analytics, entitlement, and sync can be added later without breaking offline use.

Foundation cost

£0-£5/month during vertical slice; paid EAS/Sentry/RevenueCat upgrades deferred until real release pressure.

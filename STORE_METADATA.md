## Title
TileKeeper

## Subtitle
Effortless inventory layout for tabletop gamers

## Short Description
Plan and visualise board game inventories with an offline‑first, privacy‑focused mobile app.

## Full Description
TileKeeper helps tabletop gamers organise their collection of tiles, cards, and miniatures. The app runs entirely offline, storing your data locally on your device. It provides a clean UI to create layout goals, preview how your inventory will look on the tabletop, and export layouts for sharing.

Key features:
- Offline‑first: No internet connection required for core functionality.
- No personal data collection or analytics.
- Easy import/export of inventory data as JSON.
- Visual layout preview with device‑frame screenshots.
- Customisable appearance (light/dark mode).
- Settings include a dedicated Privacy section linking to the public policy.

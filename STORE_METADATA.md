## Full Description
TileKeeper helps tabletop gamers organise their collection of tiles, cards, and miniatures. The app runs offline-first, storing your data locally on your device. It provides a clean UI to manage inventory, create layout goals, preview how your collection will look on the tabletop, save favourite layouts, and export layouts for sharing.

Key features:
- Offline‑first: No internet connection required for core functionality.
- No personal data collection or analytics.
- Easy import/export of inventory data as JSON.
- Visual layout preview for checking tabletop fit before setup.
- Saved layouts for returning to favourite arrangements.
- Customisable appearance (light/dark mode).
- Settings include a dedicated Privacy section linking to the public policy.

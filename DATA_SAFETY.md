# Google Play Data Safety Answers

**Data collected:** None

**Data shared with third parties:** None

**Data security:** All user-created data is stored locally on the device. No network transmission of personal data occurs.

**User data:** The app does not collect any personal or device identifiers.

**Location data:** Not used.

**Security practices:** The app uses HTTPS for optional catalog manifest refresh. No telemetry, analytics, advertising SDKs, or tracking SDKs are included.

## Google Play form checklist

- Data collection: **No data collected**.
- Data sharing: **No data shared with third parties**.
- Data processed ephemerally: **No**.
- Data encrypted in transit: **Not applicable for user data**; optional catalog refresh uses HTTPS for public catalog metadata.
- Users can request data deletion: **Not applicable** because the app does not collect user data. Users can delete local data by deleting the app or removing exported/backed-up files they created.
- Tracking / advertising ID: **No tracking and no advertising ID use**.
